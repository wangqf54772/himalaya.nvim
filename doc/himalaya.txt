1. INTRODUCTION                                               *himalaya-intro*

himalaya.nvim is a modern Neovim client for the Himalaya CLI email tool (v2.1+).
It provides a dedicated tabpage with a folder tree, an accounts pane and an
envelope list, all in ordinary splits. The list and every opened email are
buffers, so any buffer tabline shows them as editor tabs. HTML bodies render
through an external renderer, and the composer stays a floating popup.

==============================================================================
2. REQUIREMENTS                                        *himalaya-requirements*

- Neovim >= 0.8
- himalaya CLI v2.0+ (https://github.com/pimalaya/himalaya)
- nui.nvim (https://github.com/MunifTanjim/nui.nvim), composer and help only
- Optional for HTML rendering: w3m, lynx or pandoc
- Optional for buffer tabs: a bufferline plugin

==============================================================================
3. COMMANDS                                                 *himalaya-commands*

:Himalaya [account]
    Open the Himalaya interface in a new tabpage. If [account] is given,
    switches to that account on open (or right away when already open).

:HimalayaAccounts
    Open account picker using vim.ui.select.

:HimalayaAccount {name}
    Switch active account directly to {name}.

:HimalayaMailboxes
    Open mailbox picker using vim.ui.select.

:HimalayaMailbox {name|next|previous}
    Switch to {name} mailbox or step to next/previous.

:HimalayaWrite
    Open the floating multi-window composer.

:HimalayaSearch
    Prompt for a query and search envelopes in the active mailbox.

4. KEYBINDINGS                                           *himalaya-keybindings*

Email Listing (himalaya-envelope-listing):
    g?            Show available keybindings
    <CR>          Open email in its own buffer tab
    <LeftMouse>   Select the row and focus the listing
    <2-LeftMouse> Open email in its own buffer tab
    gq            Close the Himalaya tabpage
    ]f / [f       Next / previous mailbox (supports count)
    gF            Mailbox picker
    gA            Account picker
    R             Reload current mailbox
    ]] / [[       Next / previous page
    gw / c        Compose new email
    gr / r        Reply to selected email
    gf            Forward selected email
    gD / d        Delete selected email
    gM / m        Move email to mailbox
    gC            Copy email to mailbox
    ga            Download attachments
    gFa / gFr     Add / remove flags (seen, flagged, etc.)
    g/            Search envelopes

Mailbox Sidebar (himalaya-folder-listing):
    <CR> / click  Open the mailbox under the cursor

Account Sidebar (himalaya-account-listing):
    <CR> / click  Switch to the account under the cursor

Email Reading (himalaya-email):
    g?            Show available keybindings
    gq / q        Close the email buffer and return to the list
    gr / r        Reply to email
    gf            Forward email
    gD / d        Delete email
    gM / m        Move email
    gC            Copy email
    ga            Download attachments
    gFa / gFr     Add / remove flags
    gH            Toggle rendered HTML and its source (render_html)

Composer:
    <Tab>         Focus next field (To -> Cc -> Subject -> Body)
    <S-Tab>       Focus previous field
    <C-s>         Send email
    <C-d>         Save draft to Drafts
    <Esc>         Cancel and close composer

==============================================================================
5. CONFIGURATION                                              *himalaya-config*

Setup example:
>lua
    require("himalaya").setup({
        sidebar = { width = 30 },
        wrap_folder_navigation = true,
        icons_enabled = false,
        accounts_height = 6, -- height of the accounts pane
        custom_select = nil, -- optional function(items, opts, on_choice)
        render_html = false, -- render HTML bodies to text (w3m/lynx/pandoc)
        prefer_html = false, -- prefer HTML when text/plain also exists
        html_renderer = "w3m", -- w3m, lynx or pandoc
    })
<
